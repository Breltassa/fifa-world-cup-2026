# FIFA World Cup 2026 Website

A responsive website about the FIFA World Cup 2026, developed as part of a university Web Development course at Hochschule Worms.

## Features

- Information about teams and players
- Match schedule
- Group overview
- Stadium information
- Interactive quiz
- Order form

## Technologies

- HTML5
- CSS3
- JavaScript
- PHP
- CSS Grid & Flexbox

## My Contribution

As part of the development team, I was responsible for:

- Developing the homepage
- Developing the match schedule page
- Developing the "Best Players" page
- Designing and styling my pages with CSS
- Integrating the CSS rules of the different team members into one shared stylesheet according to the project requirements
